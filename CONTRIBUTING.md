# Contributing to MYTHOS X

Thank you for helping improve the project.

## Getting started
1. Fork the repository.
2. Create a feature branch.
3. Install dependencies with `npm install`.
4. Run `npm run dev`.
5. Before opening a pull request, run `npm run typecheck`, `npm run lint`, and `npm run build`.

## Expectations
- Keep the interface responsive and accessible.
- Prefer small, well-described pull requests.
- Do not add secrets or private user data.
- Preserve third-party license notices.
- Security features must be defensive, permission-based, and safe by default.
- Keep simulations clearly labeled; never present simulated output as live scanning or real AI analysis.

Include screenshots for substantial UI changes.
